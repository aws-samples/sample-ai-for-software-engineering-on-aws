# Mobile app development with AI-DLC (iOS first)

> **Status: planned.** This page describes the intended scope. Contributions are welcome.

## What this sample will cover

Mobile teams ship on release trains, and a release is done only when it passes app store review and
the privacy and regulatory rules that apply to the app. Faster coding becomes faster releases only if
those rules are part of the definition of done from the start. This sample builds them into AI-DLC.

Planned contents:

- steering that turns app store review guidelines and privacy requirements into checks the agents
  apply while building, starting with iOS (Swift) and followed by Android (Kotlin);
- builds on [Amazon EC2 Mac instances](https://aws.amazon.com/ec2/instance-types/mac/);
- testing on real devices with [AWS Device Farm](https://aws.amazon.com/device-farm/), driven by the
  agent through an MCP connector;
- a reference app and a one-day rehearsal guide and scorecard.

The folder layout follows the [repository convention](../../README.md#how-a-sample-is-organized).
