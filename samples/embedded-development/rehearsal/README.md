# Rehearsal: embedded development

Material for the one-day guided rehearsal described in
[docs/guided-rehearsal.md](../../../docs/guided-rehearsal.md), adapted to embedded teams.

Planned contents:

- a preparation checklist: build server access, toolchain, simulator, bench availability;
- the agenda for the day;
- a scorecard based on the team's definition of done, including the simulation and
  hardware-in-the-loop evidence the release needs.
