# Kiro steering: embedded development

Steering files that Kiro loads for every task in an embedded project.

Planned contents:

- the hardware specification of the target: board, MCU, memory map, peripherals;
- coding standards for C and C++ on the target;
- toolchain usage: cross-compiler, build system, flashing and debugging tools;
- team conventions that several teams share, kept under version control instead of in chat or wiki
  pages.
