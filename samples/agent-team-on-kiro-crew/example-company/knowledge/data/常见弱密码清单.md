# 常见弱密码清单

安全组维护的弱密码清单，共 45 个，用于《账号安全规范》ACC-2。比较时不区分大小写。清单里有公司名、产品名相关的密码（taoyuan123、privateim1 这类），因为撞库时攻击者会先试这些。

**完整清单是一个 JSON 文件：`~/workplace/taoyuan/data/weak-passwords.json`**（字符串数组）。写代码时把这个文件的内容原样放进代码里的常量，不要自己增删。
