# 品牌规范

规则编号 BR-n。网页里用 CSS 变量，变量名以 `--brand-` 开头。

## 颜色（BR-1）

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--brand-600` | `#7c3aed` | 主色：按钮、选中、强调 |
| `--brand-500` | `#8b5cf6` | 主色渐变的另一端 |
| `--brand-400` | `#a78bfa` | 次要强调、描边 |
| `--brand-300` | `#c4b5fd` | 浅色背景上的装饰 |
| `--brand-peach` | `#FF9A80` | 小桃子色：庆祝、中奖、点缀，不大面积用 |
| `--brand-ink` | `#0d0d1a` | 正文 |
| `--brand-ink-2` | `#4a4a6a` | 次要文字 |
| `--brand-stage` | `#140b2e` | 活动大屏的深色背景 |

浅色页面的背景用 `linear-gradient(160deg, #ffffff 0%, #f6f4ff 45%, #fdf3f0 100%)`；活动大屏用深色 `--brand-stage`，上面叠紫色和桃色的光斑。

## 字体（BR-2）

`"Space Grotesk", -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。数字（比如抽奖滚动的名字、倒计时）用等宽数字 `font-variant-numeric: tabular-nums`。字体文件放在仓库里，不从网上加载（前端工程规范 FE-2）。

## 动效（BR-3）

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--ease-spring` | `cubic-bezier(.34, 1.56, .64, 1)` | 弹出、揭晓 |
| `--ease-smooth` | `cubic-bezier(.65, 0, .35, 1)` | 切换、滚动 |

只动 `transform` 和 `opacity`；要尊重"减少动态效果"（前端工程规范 UX-1）。

## 小桃子（BR-4）

小桃子是品牌吉祥物，图在 `brand/mascot.svg`。可以用在登录页、空状态、庆祝时刻；不能变形、不能改颜色、不能和别的卡通形象放在一起。

## 语气（BR-5）

文案简短、友好、不夸张。不用"震撼""史上最"这类词；中奖提示写"恭喜 XX 获得 一等奖"。
