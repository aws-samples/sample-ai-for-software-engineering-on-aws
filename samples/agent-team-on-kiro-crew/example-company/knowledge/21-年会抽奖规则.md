# 年会抽奖规则

由人力资源部制定，行政部执行。规则编号 RULE-n，代码和测试里引用编号。

| 编号 | 规则 | 为什么 |
|---|---|---|
| RULE-1 | 只有**在职的正式员工**有抽奖资格。已离职（status=离职）和外包（type=外包）不参与。 | 年会预算只覆盖正式员工 |
| RULE-2 | 每人**最多中一次**。抽过的人从奖池里移除，后面的奖项不会再抽到他。 | 让更多人中奖 |
| RULE-3 | 按奖品清单的开奖顺序开奖（三等奖 → 二等奖 → 一等奖 → 特等奖），每个奖项抽满名额才能开下一个。 | 现场流程 |
| RULE-4 | **由服务端抽**，用密码学安全的随机数（Node 的 `crypto.randomInt`），不能用 `Math.random`，页面不能决定谁中奖。 | 公平、可信 |
| RULE-5 | 每次抽奖都**留记录**：时间、奖项、中奖人工号。记录可以导出给行政部发奖，导出的文件里手机号按 PII-1 脱敏。 | 可审计、能对账 |
| RULE-6 | 抽中后不能撤销。确实需要作废（例如中奖人不在现场），要写明原因，作废记录保留。 | 防止暗箱操作 |
