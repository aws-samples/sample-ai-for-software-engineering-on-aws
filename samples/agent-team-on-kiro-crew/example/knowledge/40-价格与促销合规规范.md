# 价格与促销合规规范

由法务和价格合规组制定，适用于官方商城的所有促销活动。规则编号 PRC-n，代码和测试里引用编号。

这份是桃源科技的内部规范，参照《明码标价和禁止价格欺诈规定》等价格法规制定，具体以法规原文为准。

| 编号 | 规则 | 为什么 |
|---|---|---|
| PRC-1 | **划线价**（被划掉的那个「原价」）一律取**活动开始前 7 天内这款商品的最低成交价**（活动开始前一天往前数 7 天，含两头；只算已完成的订单），由系统自动算，运营不能手填。7 天内没有成交的，取日常价。 | 用虚高的原价做对比是价格欺诈的典型情形 |
| PRC-2 | 页面上每个划线价旁边都要写明它是什么：「活动前 7 日最低价」。只写一个划掉的数字不行。 | 让顾客知道在跟什么比 |
| PRC-3 | 满减规则要写全：门槛和金额（「每满 2000 减 200」）、能不能和折扣叠加、能不能和优惠券叠加。不能只写「巨划算」「全网最低」这类说法。 | 促销条件不清楚也算误导 |
| PRC-4 | 活动时间以服务器时间为准，倒计时按服务器给的时间算，不能用顾客电脑上的时间。活动没开始或已结束，不能按活动价卖。 | 「限时」要真实 |
| PRC-5 | 活动上线前要过「上线前体检」：划线价、到手价、毛利底线（《毛利与定价规则》）、价保影响（《价保规则》）都要算出来给人看；有不合格的不能上线。 | 上线以后价格就是对全网承诺的 |
