# 前端工程规范

规则编号 FE-n（工程）和 UX-n（体验）。

| 编号 | 规则 |
|---|---|
| FE-1 | 不用内联脚本（`<script>` 里写代码、`onclick=` 这类属性），页面有内容安全策略（CSP），内联脚本会被拦。 |
| FE-2 | 不引用第三方域名的脚本、字体、图片、样式（不用 CDN），资源都放在仓库里。 |
| FE-3 | 用户或数据里的文字插进页面前要转义，不能直接拼 HTML。 |
| FE-4 | 不在前端代码里写死密钥、令牌。 |
| UX-1 | 动画要尊重系统的"减少动态效果"设置（`prefers-reduced-motion: reduce` 时关掉滚动和粒子，直接显示结果）。 |
| UX-2 | 图片有替代文字（alt），装饰性图片 `alt=""`。 |
| UX-3 | 文字和背景的对比度够看清：正文至少 4.5:1，大屏上的大字至少 3:1。 |
| UX-4 | 颜色、字体用品牌规范里的变量（`--brand-*`），不在页面里随手写新颜色。 |
