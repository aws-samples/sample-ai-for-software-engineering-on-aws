# 桃源科技内部网页：目录

| 路径 | 是什么 |
|---|---|
| `server/routes/` | 接口 |
| `server/data/` | 数据（从知识库取来，原样放） |
| `web/pages/` | 页面：每个页面一个 `<页面名>.js`，在 `index.js` 里登记 |
| `web/styles/` | 样式：`tokens.css` 品牌变量、`base.css` 全站组件，每个页面一个 `<页面名>.css` |
| `web/motion/` | 品牌动效 |
| `deploy/` | 部署配置 |
| `tests/` | 测试；`tests/enterprise/` 是公司下发的检查 |
| `docs/aidlc/` | 各阶段的产出 |
